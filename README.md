# PROJECT-1-FISH-AND-CHIPS
Welcome to Fish N' Chips. 

Embark on a journey in a vast world full of surprises with your trusty rod, catch the rarest fishes from the Sea!
Be careful, You might get carried away with the items you catch
Buy upgrades, or gamble it for more. The choice is yours to catch!

- GOAL:
    * Fish, and get rich!!!
    * Gamble chips for Overpowered gears or  lose it all...

# HOW TO RUN FISH N' CHIPS:
1. Extract the Zip File.
2. Press ```main.exe```
3. Begin playing!

### Gameplay
| Key / Input | Action |
|---|---|
| `W A S D` | Move |
| `TAB` | Open/Close Inventory |
| `Left Click (In Inventory)` |Select Item  |
| `Right Click (In Inventory)` | Lock/Unlock Item |
| `Q` | Sell |
| `E` | Fish |
| `F ` | Open Shop |
### Others:
| Key / Input | Action |
|---|---|
| `P` | Toggle Debug | 
| `esc` | Quit Game | 
# GAME
1. Go to the wooden platform (dock)
2. ```Press E``` to Fish
3. Wait a few seconds, until you catch a fish!
4. preview your catch by ```pressing TAB``` (opens inventory)
5. If your ready to sell it, head over to the dark brown structure. If not, ```right click``` the item to prevent it for being sold
6. Sell the item
7. Rinse and Repeat! (Shop isnt fully implemented yet)



## Reason for Making:

(This game is Heavily Inspired by the roblox game "Fisch")
*Link: https://www.roblox.com/games/16732694052/Fisch*

I struggled thinking of a program/app to make until i stumbled upon the idea of creating a game. I landed on this idea because i actually thought of a fishing game, but when I asked a friend of mine for a game name idea, he said "Fish N Chips".

 "Chips" reminded me of casino chips, so why not make a game with gambling elements since I find unpredictability fun. (plus replayability is better when something is random)
